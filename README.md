# LumeTracker — FinTech Portfolio & Crypto Tracker

> A modern, real-time cryptocurrency portfolio tracker and financial dashboard built with **React**, **Context API**, and **Tailwind CSS**. Monitor live market prices, track your personal asset holdings, analyze profit/loss margins, and visualize trends with interactive charts.

---

## 🚀 Features

* **Real-Time Market Data**: Live price tracking, market caps, 24h/7d percentage changes, and volume via the CoinGecko API.
* **Interactive Portfolio Management**: Add, edit, or remove your crypto holdings (quantity, purchase price/cost basis).
* **Profit / Loss (P&L) Analytics**: Automatic calculation of total portfolio value, net profit/loss, and ROI in real time.
* **Interactive Charts**: Visual breakdown of portfolio allocation (pie/donut charts) and historical performance trend lines using **Recharts / Chart.js**.
* **Multi-Currency Support**: Switch display pricing between USD, EUR, INR, and more.
* **Watchlist & Search**: Search for any coin by name or symbol and pin favorites to your personal watchlist.
* **Local Persistence**: Client-side state persistence using `localStorage` so your portfolio stays saved across browser sessions.
* **Responsive Design**: Clean mobile-first layout styled with Tailwind CSS.

---

## 🛠️ Tech Stack

* **Frontend Library**: React.js (Hooks, Router)
* **State Management**: Redux Toolkit / React Context API
* **Styling**: Tailwind CSS + Lucide React (Icons)
* **Data Visualization**: Recharts / Chart.js
* **APIs**: CoinGecko REST API
* **Deployment**: Vercel / Netlify / Firebase Hosting
